# L4D2 LAN Kit [![English](https://img.shields.io/badge/README-English-blue)](README.md)

Выделенный сервер Left 4 Dead 2 для спокойного прохождения по локальной сети: два игрока, два напарника и автоматическая смена кампаний.

## Установка

Нужны Windows 10/11 x64, Windows PowerShell 5.1, **частная** локальная сеть и интернет. У игроков должны совпадать официальные Steam-версии игры. На Mac можно использовать CrossOver.

1. Скачайте репозиторий как ZIP и распакуйте.
2. Откройте **Install.cmd** и подтвердите запрос администратора. Он скачает официальный сервер и закреплённые зависимости, настроит сервер, ограниченное правило брандмауэра и задание для ручного запуска.
3. После установки запустите **Start.cmd**. Сама установка игровую сессию не запускает.

При первом запуске создаётся **kit.config.json** из `config.example.json`. В нём задаются `ServerRoot`, `ListenIPv4`, `Port`, `StartMap`, `Hostname`, `Profile` и `EnableKeepLaser`. Единственный адрес частной сети определяется автоматически; иначе задайте `ListenIPv4`. Скрипты не меняют политику выполнения PowerShell.

## Игра и управление

- **Start.cmd** запускает сервер; **Stop.cmd** завершает текущую сессию.
- **Check.cmd** проверяет девять обязательных плагинов, инициализацию конфигурации/напарников и новые ошибки без изменений.
- В консоли игры на каждом компьютере: `connect <локальный-IP-сервера>:27016`.

Сервер работает под встроенной LOCAL SERVICE; закрытие терминала или удалённого рабочего стола его не останавливает. Автозапуска Windows и RCON нет. Команды запрашивают права администратора. Повторная установка сохраняет изменения; при конфликте неизвестных файлов останавливается.

Перед изменениями остановите сервер. Игровые переопределения задаются в `<ServerRoot>/left4dead2/cfg/server.cfg` после настроек профиля; ограничения локальной сети, выключенных читов и RCON сохраняются.

## Возможности

| Компонент | Возможности |
|---|---|
| Left4Bots2 + Left4Lib | Помощь напарников: подбор и передача предметов, дефибрилляторы; полное автопрохождение выключено. |
| ACS + Mission Manager + Changelevel | Цикл всех 14 официальных кампаний после финалов; без голосований и пропуска после неудач. |
| Path To Goal | `!ptg` показывает путь; `!ptg_menu` настраивает подсказки. |
| Item Hint | Shift+E или `!mark` отмечает предмет, противника или место. |
| Weapon Drop | `!drop` бросает удерживаемое оружие; выбрасывание дополнительного оружия запрещено. |
| Keep Laser Sights (опция) | Переносит имеющийся лазер при замене оружия. |
| Who Called the Horde | Показывает, кто вызвал поддерживаемое событие орды. |

Keep Laser Sights **по умолчанию выключен**. `"EnableKeepLaser": true` включает загрузку и компиляцию авторского [исходника](https://forums.alliedmods.net/attachment.php?attachmentid=200229&d=1681243413). При HTTP 403 поместите исходник в `runtime/downloads/l4d2_keeplasers.sp` и повторите Install.cmd; SHA проверяется. Left4Bots2/Left4Lib скачиваются у авторов.

Профиль `casual`: Easy, 24 обычных заражённых, случайная орда 8–24, крупная орда 40, штатный интервал Easy 120–240 секунд. Коэффициент урона по телу равен 1 вместо штатных для Easy 2: обычные заражённые живучее. Сюжетные события могут задавать свои параметры орды.

## Необязательные изменения клиентов и ограничения

[Модель M4A1 с ADS](https://steamcommunity.com/sharedfiles/filedetails/?id=2972592952) заменяет **только M16**; серверный [Weapon System](https://github.com/IA-NanaNana/l4d2-aim-down-sight) обеспечивает прицеливание. [Vanilla+ Weapon Sounds](https://steamcommunity.com/sharedfiles/filedetails/?id=3567477734) меняет звуки. Эти пакеты устанавливаются отдельно и в репозиторий не входят. Выбирайте одну модель на оружие; у M4 и звукового пакета пересекаются звуки винтовки.

На одном проверенном Mac использовались 1800×1169, графика Wine, MSync и отключённый голосовой чат игры. Настройки подбираются под ваш экран; стабильные 60–120 FPS не гарантируются.

Постепенного открытия карт и автосохранения глав/экипировки нет. После перезапуска используется `StartMap`. Проверена существующая локальная конфигурация; установка на чистый компьютер пока не подтверждена.

Проверка разработчика: `powershell.exe -NoProfile -File tests/Test-Validation.ps1` (также подходит `pwsh`).
