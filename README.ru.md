# L4D2 LAN Kit [![English](https://img.shields.io/badge/README-English-blue)](README.md)

Комплект сервера Left 4 Dead 2 для спокойного прохождения по локальной сети: два игрока, два напарника и все 14 официальных кампаний по порядку.

## Установка

Нужны Windows 10/11 x64, Windows PowerShell 5.1, **частная** локальная сеть, интернет и место примерно для **10 ГБ серверных файлов**. Игроки отдельно устанавливают совпадающие Steam-версии игры. На Mac можно использовать CrossOver.

1. Скачайте репозиторий как ZIP и распакуйте.
2. Откройте **Install.cmd** и подтвердите запрос администратора. Он скачает официальный сервер через SteamCMD и закреплённые зависимости, затем настроит ограниченное правило брандмауэра и задание для ручного запуска.
3. После установки запустите **Start.cmd**. Сама установка игровую сессию не запускает.

В ZIP находятся установщик, исходники и настройки. Большие игровые и серверные файлы скачиваются при установке и нужны для дальнейшей работы сервера.

При первом запуске создаётся **kit.config.json** из `config.example.json`. В нём меняются папка сервера, адрес, порт, название и стартовая глава. Единственный адрес частной сети определяется автоматически; иначе задайте `ListenIPv4`.

## Игра и управление

- **Start.cmd** запускает сервер; **Stop.cmd** завершает текущую сессию.
- **Check.cmd** проверяет обязательные плагины, инициализацию конфигурации/напарников и новые ошибки без изменений.
- В консоли игры на каждом компьютере: `connect <локальный-IP-сервера>:27016`.

Пустой сервер начинает инициализацию раунда после входа первого игрока.

Сервер работает под LOCAL SERVICE; закрытие терминала или удалённого рабочего стола его не останавливает. Автозапуска Windows и RCON нет. Повторная установка сохраняет изменения; при конфликте неизвестных файлов останавливается.

Перед изменениями остановите сервер. Игровые настройки в `<ServerRoot>/left4dead2/cfg/server.cfg` переопределяют профиль; ограничения локальной сети, выключенных читов и RCON сохраняются. `StartMap` в `kit.config.json` задаёт стартовую главу следующего запуска.

## Возможности

| Компонент | Возможности |
|---|---|
| Left4Bots2 + Left4Lib | Помощь напарников: подбор и передача предметов, дефибрилляторы; полное автопрохождение выключено. |
| ACS + Mission Manager + Changelevel | По умолчанию начинает с No Mercy, затем переключает все 14 официальных кампаний по кругу; без голосований и пропуска после неудач. |
| LAN Horde Limits | Применяет профиль орд к поддерживаемым сюжетным событиям, сохраняя боссов и стадии финалов. |
| Path To Goal | `!ptg` показывает путь; `!ptg_menu` настраивает подсказки. |
| Item Hint | Shift+E или `!mark` отмечает предмет, противника или место. |
| Weapon Drop | `!drop` бросает удерживаемое оружие; выбрасывание дополнительного оружия запрещено. |
| Keep Laser Sights (опция) | Переносит имеющийся лазер при замене оружия. |
| Who Called the Horde | Показывает, кто вызвал поддерживаемое событие орды. |

Keep Laser Sights **по умолчанию выключен**. `"EnableKeepLaser": true` включает загрузку и компиляцию авторского [исходника](https://forums.alliedmods.net/attachment.php?attachmentid=200229&d=1681243413). При HTTP 403 поместите исходник в `runtime/downloads/l4d2_keeplasers.sp` и повторите Install.cmd; SHA проверяется. Left4Bots2/Left4Lib скачиваются у авторов.

Профиль `casual`: **Easy**, 18 обычных заражённых, случайная орда **6–18**, крупная орда **30**, штатный интервал Easy 120–240 секунд. Коэффициент урона по телу равен 1 вместо штатных для Easy 2: обычные заражённые живучее.

LAN Horde Limits через Left4DHooks 1.174 ограничивает поддерживаемые положительные значения `DirectorOptions` теми же пределами. Минимальный и максимальный таймеры сюжетных волн не опускаются ниже 6/10 секунд. Отсутствующие, нулевые и отрицательные значения, боссы, специальные заражённые и стадии финалов сохраняются.

Если напарники перестали следовать за вами, отправьте в игровой чат по очереди, без `!`:

```text
bots cancel all
bots follow
```

## Ограничения

Включённые серверные моды работают с обычными клиентами. Модели оружия и замены звуков ставятся отдельно на клиентах и в комплект не входят. Серверный плагин прицеливания Weapon System ADS не устанавливается.

Постепенного открытия карт и автосохранения глав/экипировки нет. После перезапуска используется `StartMap`.

Проверено в Windows PowerShell 5.1: 57 изолированных тестов; установка и переустановка с официальным кэшем, проверенным SteamCMD, с сохранением настроек; запуск, повторный запуск, проверка, остановка, перезапуск и ответ по локальной сети. Установка на чистую ОС и новая игровая сессия двух клиентов ещё не проверены.

Проверка разработчика: **Test.cmd** выполняет изолированные проверки конфигурации, целостности комплекта и восстановления установки.
